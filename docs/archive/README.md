# Archive

Frozen historical documents. Contents are **not maintained**:

- `legacy/` — pre-refactoring documentation (Panoptiscan-era and early Saphir docs, kept for reference).
- `plans/` — completed planning documents (refactoring, testing, validation-test runs).

Cross-references *inside* archived documents point to the file locations as they
were at the time of writing; they are intentionally not updated.

Active documentation lives at the [`docs/`](../Readme.md) root.
